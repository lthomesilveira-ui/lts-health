# Functional depth package — issue #265

Status: implementation prepared; CI, public promotion and authenticated visual review are required before release. No health payload is recorded here.

## Product scope

Preserve the structural layout accepted directionally by the user. Training adds a complete paginated history, query by session/exercise/place, year filtering, explicit return paths and read-only exercise occurrences. Curves use working sets of the same named exercise, known equipment and location, exact unit, one session per day. They describe recorded loads, not strength estimates or recommended intensity.

Labs provides every available named marker, including textual and single results, with search and a full picker. Origin, unit and method cohorts remain distinct; unknown metadata, censored values and duplicate dates cannot manufacture a curve. Native point lookup exposes the selected date, value and reference on touch/keyboard. Every result remains in paginated history, not only comparable results.

Composition provides source/period selection, full paginated measurement history and read-only measurement detail. Segmental linkage requires unambiguous source/date/file context. Lean segmental mass is not relabeled skeletal muscle. Ambiguous measurements remain accessible but out of automatic comparison. No aesthetic score, target body or inferred measurement is added.
