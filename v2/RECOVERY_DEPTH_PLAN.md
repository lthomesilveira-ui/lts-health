# Recovery depth package

This package will deepen Recuperação & análises without changing health-source precedence or inferring causal/clinical conclusions.

## Scope

- expose complementary recovery signals as source-separated evidence series;
- show source, metric, unit, first/last preserved observation, coverage count and review-required duplicate days;
- never average across devices, source families or incompatible units;
- keep candidate/held evidence distinct from canonical values;
- preserve absence as absence rather than zero;
- add desktop/mobile browser gates for recovery source separation and no-overflow behavior.

## Release rule

Promote only after static checks, browser gates, dashboard reference checks and functional-depth checks are green. Real authenticated checks remain authoritative where they apply.
